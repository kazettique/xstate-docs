## Stately Studio 與 XState 該如何選擇？

Stately Studio 與 XState 結合使用時最具威力。運用 Stately Studio 的視覺化編輯器協作建構應用程式邏輯，再透過 XState 將該邏輯整合至程式碼庫。

您亦可不使用 Stately Studio 直接在程式碼庫中運用 XState；若尚未熟悉 XState，亦歡迎先使用 Stately Studio 進行建模。
