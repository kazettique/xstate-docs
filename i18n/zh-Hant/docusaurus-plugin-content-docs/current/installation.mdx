# 安裝指南

XState 擁有**零依賴性**，可在任何 JavaScript 可執行的地方執行。您可以使用最喜歡的套件管理員安裝 XState，例如 [npm](https://www.npmjs.com/)、[pnpm](https://pnpm.js.org/) 或 [yarn](https://yarnpkg.com/)。

<Tabs>
<TabItem value="npm" label="npm">

```bash
npm install xstate
```

</TabItem>

<TabItem value="pnpm" label="pnpm">

```bash
pnpm install xstate
```

</TabItem>

<TabItem value="yarn" label="yarn">

```bash
yarn add xstate
```

</TabItem>
</Tabs>

## CDN

您也可以從各種 CDN 匯入 XState：

- [esm.run](https://esm.run):

```ts
import { createMachine, createActor } from 'https://esm.run/xstate';
```

- [esm.sh](https://esm.sh):

```ts
import { createMachine, createActor } from 'https://esm.sh/xstate';
```

- [Skypack](https://www.skypack.dev):

```ts
import { createMachine, createActor } from 'https://cdn.skypack.dev/xstate';
```
